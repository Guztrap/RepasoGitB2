## HU-01 · Crear un Login

**Como** estudiante del curso,  
**quiero** poder hacer login en la pantalla de acceso
**para** poder revisar las calificaciones de  las materias.

### Criterios de aceptación

- [ ] Tener una pantalla de login con los campos de usuario y contraeña
- [ ] Validar el intento de fallido o exitoso
- [ ] Al tercer intento fallido que se bloqueé la cuenta
- [ ] Tener el botón de cambio de password donde solicite el correo para la restauración
- [ ] Que llegue el correo al usuario y restarue su contraseña

### Notas técnicas

- Se debe escribir un archivo en Pseudocódigo con todos los pasos
- Se debe considerar la parte de base de datos
- Se debe considerar el generar las pruebas unitarias
